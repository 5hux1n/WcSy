微信 iOS 插件 · 实验中

理解聊天，多一个观察角度。

实验性的微信情景分析插件。在已启用的聊天中分析对方新收到的文字消息，并在消息下方展示仅本机可见的 JEV 情景判断。

查看实验项目 ↗阅读项目说明 ↗

项目仍是半成品，当前快照未完成真机验收和线上效果验证。模型判断不等于已确认的真实动机，不作为稳定功能承诺。

项目能做什么

逐聊天开启

为单聊或群聊分别启用，分析当前已加载的文字上下文。

多维情景判断

观察情景、意图、情绪、回应期待等维度，展示选项分布与可能的备选解释。

本机查看

结果附在消息行下方，点击查看详情；聊天菜单中可查看状态或重新分析。

开始使用

  1. 阅读仓库中的已知问题和兼容性说明，选择与安装环境对应的实验包，避免重复注入。
  2. 在插件设置中填入自己的 JEV API Key，并启用相应聊天。
  3. 分析会将聊天窗口中的文字上下文发送给 JEV，结果不会作为微信消息发送；这是联网功能。
