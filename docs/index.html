使用时，哪些信息会离开设备？

所选聊天窗口内的文字上下文会发送给 JEV API，这不是纯离线功能。API Key 存于本机 Keychain，图片和语音媒体文件不上传。结果不写入微信聊天数据库。

当前适配范围是什么？

代码尝试适配微信 8.0.78；其他版本与插件组合不保证兼容。新消息分析和布局仍需设备验证。
