## 当前实现的边界

- 这仍是附着在原消息行中的本地预览视图。读取到引用视图属性才标为“微信引用”，否则标为“系统备用”。没有证据表明已成功复用微信内部完整的引用组件。
- 只能分析当前打开且开启咨询的聊天。单次读取最近 20 条；超过窗口的高频消息可能错过，无法确认发送方向时跳过。
- 请求结果根据请求时捕获的上下文解释；返回时必须确认目标消息仍一致，已经滑出窗口的目标不挂载。
- 磁盘按聊天标识和本地消息 ID 保存，尚未增加微信账号命名空间；多账号切换、本地消息 ID 重用未验证。
- 存储失败会写不含聊天正文的错误日志。网络失败保留旧决策，可通过“咨询”菜单手动重试，不会无限自动重试。
- 模型置信分不是经校准的心理状态概率。当前是五字段决策分类，并非截图中对动机概率的自由推断。
